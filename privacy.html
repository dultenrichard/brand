Privacy & data

Plain language. Minimal collection.

This site is built to collect as little information as practical. This page explains what is processed, why it is used, how long it is kept, and what choices you have.

01 / Scope

Who is responsible for this site

This is the personal website of Dulten Richard Fromentin, based in Ontario, Canada. The site is used as a public portfolio and record of experience, skills, awards, projects, and contact information.

Privacy questions or requests can be sent to fromentindulten@gmail.com.

02 / Analytics

What the site measures

The site uses Umami Cloud for limited, privacy-focused analytics. The analytics account uses the EU data region. Umami does not use analytics cookies and does not track visitors across unrelated websites.

The site may record page views, referring site, browser, operating system, device type, broad geographic information, and deliberately defined events such as navigation use, section views, scroll milestones, skill filters, contact intent, email-link clicks, social-profile clicks, outbound domains, and document or certificate views.

Free-form contact messages, names, email addresses, and typed skill-search text are not intentionally sent to analytics. URL query strings are excluded from automatic Umami page tracking. Only selected UTM campaign fields may be recorded.

Umami states that an IP address may be used transiently to determine location and create an anonymous session identifier, but the IP address itself is not stored. Anonymous sessions are not used here to identify named individuals.

03 / Hosting

GitHub Pages

This website is hosted on GitHub Pages. GitHub states that when a GitHub Pages site is visited, the visitor's IP address is logged and stored by GitHub for security purposes. That processing is controlled by GitHub, not by this site's analytics code.

See GitHub's Privacy Statement ↗ for GitHub's own processing and retention practices.

04 / Contact

When you contact me

The contact form on this site does not submit your message to a website database. It prepares an email in your own mail application. Nothing typed into that form is intentionally transmitted by this site unless you choose to send the resulting email.

If you send an email, the information you include—such as your name, email address, organization, and message—is processed for the purpose of reading and responding to your enquiry. Email is currently handled through Google Gmail.

06 / Choices

Analytics controls

This site's own analytics are disabled automatically when a browser sends a recognized Global Privacy Control or Do Not Track signal. You can also disable or re-enable Umami analytics for this browser below.

A small local browser preference is used only to remember this choice. Disabling this site's analytics does not control processing performed independently by GitHub as the hosting provider.

07 / Rights

Access, correction, deletion, and objection

Depending on where you live and which law applies, you may have rights to ask what personal information is held about you, request correction or deletion, restrict or object to certain processing, or obtain a copy of information you provided.

Because the site's analytics are designed not to identify named visitors, it may not be possible to connect an anonymous analytics session to a specific person. Requests concerning email correspondence can be handled using the email address or context you provide.

This site does not sell personal information, rent personal information, or use visitor data for targeted advertising.

08 / International processing

Where processing can happen

Umami analytics for this site uses the EU data region. GitHub and Google are separate service providers with their own infrastructure and privacy terms, and they may process information in countries other than the visitor's country.

The site's approach is based on common privacy principles including transparency, purpose limitation, data minimisation, storage limitation, security, and user access or deletion rights where applicable.

09 / Changes

Policy updates

This page will be updated when the site's data practices, analytics provider, retention periods, or material privacy practices change. The date at the top of the page shows the latest revision.
